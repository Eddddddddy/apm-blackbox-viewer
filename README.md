# APM 黑匣子查看器

在浏览器中回放和分析 ArduPilot 四轴飞行器的 DataFlash 日志。

[打开查看器](https://eddddddddy.github.io/apm-blackbox-viewer/)

## 使用

1. 从飞控 TF 卡的 `APM/LOGS` 目录打开或拖入 `.BIN` 文件。页面初次打开时显示一份合成示例。
2. 默认定位到最后一次记录到离地的飞行。底部时间轴用色带显示飞行模式，并标记解锁、离地和上锁。
3. 点击图表、时间轴或事件可定位播放头。在曲线上横向拖动可框选并放大到这一段时间。Shift + 拖动平移，滚轮缩放，F 恢复当前飞行的完整视图。
   播放栏的前后按钮和键盘左右键共用同一帧步长（默认 1 帧）。Space 播放或暂停，A 打开频谱。
4. 飞行概览包含姿态、遥控摇杆输入、高度、电机转速和电池电压。也可切换 PID、视觉与定位、动力与振动预设，或搜索自定义信号。

逐帧步进使用日志的记录时间戳，优先使用 ANG，其次选用 RATE、ATT 等时间序列。图例随播放头更新。采样频率较低的信号可能在连续几帧内保持同一读数。

Quad X 模型根据日志中的实际姿态转动。RPM 按 `SERVOx_FUNCTION` 映射到各个电机。双摇杆读取 `RCIN` / `RCI2`，使用日志里的通道映射、校准和反向参数，可切换 Mode 1–4。

频谱使用播放头附近的 `GYR` 数据，日志包含滤波前后记录时会叠加显示。动态陷波标记来自频谱窗口中点附近的 `FTN` 记录。CSV 导出当前时间范围的样本，摇杆预设以校准后的百分比导出，单次上限 25 万点。

## 隐私

日志只在浏览器的 Web Worker 中分块读取，CSV 在本地生成。静态页面由 GitHub Pages 提供，网页没有日志上传接口或分析统计脚本。仓库的示例数据由代码生成。

## 开发

需要 Node.js 22.12+ 或 Node.js 24+。

```sh
npm ci
npm run dev
```

`npm test` 运行基于合成日志的测试，`npm run build` 将静态网站输出到 `dist/`。提交到 `main` 后，GitHub Actions 会运行测试并发布 GitHub Pages。

| 路径 | 内容 |
| --- | --- |
| `src/app/` | 查看器界面和回放状态 |
| `src/components/` | 曲线、时间轴、3D 机身和摇杆组件 |
| `src/dataflash/` | 日志解析、后台工作线程、频谱和合成示例 |
| `src/replay/` | 飞行状态、信号预设、姿态与遥控映射 |
| `test/` | 解析和回放测试 |
| `.github/workflows/pages.yml` | 测试、构建和发布流程 |

依赖的许可声明随构建输出到 `third-party-notices.md`。
